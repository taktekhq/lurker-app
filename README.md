# lurker-app

A post queue and a comment queue for Reddit and Hacker News, plus share
photos from your iPhone to get Reddit post drafts back. You post
everything yourself.

See [SPEC.md](SPEC.md) (photo shares) and [SPEC-v2.md](SPEC-v2.md)
(queues, growth). Setup for each part is in its folder: `worker/`,
`drafter/`, `ios/`. The engine that fills the queues lives in a separate,
private repo.
